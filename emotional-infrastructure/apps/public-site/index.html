Emotional Infrastructure™ Governance Runtime

Candidate governance architecture · reference implementation · developer prototype

This is a reference implementation, not a certified, production-ready, legally compliant, regulator-approved, externally audited, clinically validated, or benchmark-proven system. See docs/CLAIM_BOUNDARY.md in the repository for the full claim boundary.

What this is

A working developer reference implementation for AI-mediated trust governance: a Consent Token Protocol (CTP), PDEV middleware (Purpose, Dignity, Evidence, Veto), an Emotional Governance Layer (EGL), Temporal Affective Regulation (TAR), Trajectory Governance, a hash-chained Dignity Ledger™, a Behavioral Signal Taxonomy, a rule-based Policy Engine, a Claim Boundary Scanner, and a TypeScript SDK -- all backed by real endpoints, real PostgreSQL persistence, and a real governance dashboard.

Governance modules

CTP

Scoped, revocable, context-bound consent tokens (ES256 JWT, ≤300s lifetime).

PDEV

Purpose / Dignity / Evidence / Veto gate evaluation for every protected request.

EGL

Signal-tier classification, a dynamic circuit breaker, and consent step-up.

TAR

Inference is not authorization -- time-boxed, risk-scoped action authorization.

Trajectory Governance

System-level, content-free longitudinal authority-formation checks.

Dignity Ledger™

Append-only, hash-chained, metadata-only governance decision log.

Policy Engine

Priority-ordered, auditable rule evaluation.

Claim Boundary Scanner

Flags overclaiming language in public-facing copy.
