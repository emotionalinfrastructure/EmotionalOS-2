# Validation

See [`docs/VALIDATION_PLAN.md`](../../docs/VALIDATION_PLAN.md) for the
authoritative record of what has and has not been executed against this
codebase, and [`docs/ACCEPTANCE_CHECKLIST.md`](../../docs/ACCEPTANCE_CHECKLIST.md)
(mirrored from the binding upload) for the acceptance checklist this
implementation was built against.

This directory exists as the governance-side pointer for validation
artifacts (test run records, future audit reports). It intentionally
contains no independent claims beyond what `docs/VALIDATION_PLAN.md`
states -- duplicating validation status in two places invites drift.
